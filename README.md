# VacGuide Studio

VacGuide 几何设计 GUI v0.1。纯 HTML/CSS/JavaScript，所有资源本地包含。

## GitHub Pages

本仓库根目录就是网站发布目录。仓库 Settings → Pages 中选择 **Deploy from a branch**，分支 **main**，目录 **/(root)**，保存即可。

## 完整开发包

[下载完整项目 ZIP](VacGuide_GitHub_Pages_20261023.zip)

完整包包含相同的网站源码、15 项测试、GitHub Actions 自动部署配置、中文说明和 Windows/macOS 启动脚本。包里的 `dist/` 对应本仓库根目录的网站文件。完整包适合继续开发或建立使用 Actions 部署的新仓库；本仓库当前采用 main 根目录发布。

## 使用

- 编辑 1–12 个关节的角度、旋转平面、方向与尺寸。
- 查看三维几何、平面装配与两组时序规划。
- 本地自动保存；导入导出 JSON 项目。
- 导出 SVG 装配参考、CSV 参数和可打印装配指南。

从旧网站迁移设计：在旧站点击「保存项目」导出 JSON，在新站点击「导入」。不同网址之间的浏览器自动保存不共享。

## 模型范围

面片和 guide 是独立零件，通过胶带连接后整体置入气囊。此版本提供矩形面片串联结构的几何规划。Guide 图形、动画和时序为设计示意；实际压力、膜、力、碰撞、气路及回弹需要相应物理模型与实验。SVG 用于装配参考。多边形面片及连接边编辑是后续功能。
